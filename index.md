### Multimodal Fall Detection System

**Keywords:** multimodal sensing, human monitoring, real-time system  

Developed an end-to-end fall detection pipeline integrating audio and vision signals for indoor safety monitoring. The system performs synchronized multimodal inference and supports real-time alert delivery via Telegram.

**My role:** Designed the multimodal fusion pipeline and temporal inference logic.  
**Tech stack:** Python, PyTorch, OpenPose, audio processing, Telegram Bot API  

---

### Multi-view 3D Human Motion Analysis for Indoor Fitness

**Keywords:** 3D pose, SMPL-X, temporal modeling  

Led the 3D component of a multi-view human motion analysis system for indoor fitness scenarios. The pipeline reconstructs temporally consistent human motion using SMPL-X and supports downstream tasks such as repetition counting and abnormal-motion detection.

Particular attention was paid to handling occlusion, viewpoint variation, and noisy keypoints in real environments.

**My role:** 3D pipeline design, temporal modeling, robustness tuning  
**Tech stack:** PyTorch, SMPL-X, multi-view geometry  

---

### Human-Centered Multimodal Explanation with Cue–Simile Reasoning (Ongoing)

**Keywords:** Explainable AI, Human-AI Interaction, Multimodal Reasoning  

I am currently developing a human-centered explanation framework that studies how different explanation mechanisms affect user understanding of AI predictions.

The current pipeline models two reasoning paths:

- stimulus → cue extraction → class prediction  
- stimulus → simile retrieval → analogy trigger → class prediction  

**Status:** In progress, under active refinement.
